Staff Operating Guidelines

1. Checkout Verification Workflow

Always confirm borrower identity using their physical UAlbany ID card or active NetID lookup. Verify all included accessories against the equipment kit list before completing checkout in New checkout.

2. Equipment Check-in & Quarantine

Returned equipment must not be shelved immediately. Process the return via Return equipment, route the device to the preparation queue, and perform data wipe and sanitization steps before marking it ready for lending.

3. Damaged or Incomplete Returns

If an item is returned damaged or missing components, select "Damaged — supervisor inspection required" in the return form, record detailed notes, and place the kit in the quarantine hold locker.
